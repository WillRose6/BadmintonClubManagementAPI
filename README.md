\# Badminton Club Management API



A RESTful backend API built with \*\*C#\*\* and \*\*ASP.NET Core\*\* designed to manage badminton club operations, including player profiles, court bookings, and league rankings.



\## Tech Stack

\* \*\*Language:\*\* C# (.NET 9)

\* \*\*Framework:\*\* ASP.NET Core Web API

\* \*\*Data Access:\*\* Entity Framework Core, SQL

\* \*\*Testing:\*\* xUnit, Moq



\## Features

\* \*\*Player Management:\*\* CRUD operations for club members.

\* \*\*Court Bookings:\*\* Schedule and manage court allocations.

\* \*\*Unit Testing:\*\* Validated core application logic using xUnit.



\## Upcoming Features

\* League Rankings: Track player standings and match results.

\* JWT Authentication for secure endpoints

\* FluentValidation for incoming request payloads
